# Domain docs

Use a single-context layout: root CONTEXT.md and docs/adr/.

Before exploration, read CONTEXT.md and relevant ADRs when
present. If CONTEXT-MAP.md exists, follow its relevant pointers.

Proceed silently when these files are absent. Create domain
documents only as terms or decisions are resolved.

Use the glossary's vocabulary. Explicitly flag proposals that
conflict with an existing ADR.
